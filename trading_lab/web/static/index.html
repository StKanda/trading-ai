PROTOCOLE V8

Ce que l'application mesure

Les unités 5, 10 et 15 minutes sont construites à partir de bougies de 5 minutes terminées, ancrées sur l'ouverture de la place. Les niveaux et figures n'utilisent que les informations déjà disponibles.

Trois notions distinctes : le score de sélection est une règle descriptive sur 100 ; le score de figure est une qualité géométrique sur 100 ; le score RF est une sortie non calibrée du modèle. Aucune de ces valeurs n'est présentée comme une probabilité de trade gagnant validée.

Le backtest se lance en ligne de commande. Il compare les ablations A/B/C/D, sépare recherche historique et test final, applique frais et slippage, simule le levier et ferme avant la fin de séance. Le scanner multi-actifs n'est pas encore une stratégie de portefeuille évaluée.

Les données Yahoo sont interrogées périodiquement. Leur délai n'est pas garanti. La démo est synthétique. Le scénario d'achat n'est pas un ordre et aucun courtier n'est connecté.

Le chat actuel explique les calculs avec des règles locales ; il ne s'agit pas encore d'un LLM. La méthode, les commandes et les limites détaillées sont dans le README fourni.
